## 技術要件（厳守）
- **単一の自己完結HTMLファイル**。外部リクエスト完全禁止（CSPでブロックされる）: Google Fonts・CDN・外部画像・fetch すべて不可。CSS/JSは全てインライン。
- ファイル先頭に `<!DOCTYPE html>` や `<html>/<head>/<body>` タグを**書いてよい**（ローカルプレビュー用。後工程でそのまま使う）。`<title>` 必須。
- フォントはシステムフォントスタックのみ（日本語: "Hiragino Kaku Gothic ProN", "Hiragino Sans", "Yu Gothic", "Noto Sans JP", "Meiryo", sans-serif / 明朝系が必要なら "Hiragino Mincho ProN", "Yu Mincho", serif / 欧文ディスプレイ: "Avenir Next", "Futura", "Helvetica Neue" 等から意図を持って選ぶ)。letter-spacing・weight・サイズスケールで個性を出すこと。
- 画像は次の相対パスで参照（後工程で data URI に自動置換するので、パス文字列を正確に）:
  - `img/HERO_BG.webp` — 天井の電線管・ケーブルラック群を見上げた暗めのムーディーな写真（1920x1072, 暖色照明）
  - `img/WORK_CONDUIT.webp` — 革手袋の職人の両手がカラフルなケーブル束を電線管へ入線する接写（1920x1072, 暖色）
  - `img/WORK_PANEL.webp` — 配線美しい分電盤とストリッパーを持つ手元（1920x1072）
  - `img/QR_INSTAGRAM.png` — Instagram QRコード (400x400)
  - `img/QR_LINEWORKS.png` — LINE WORKS QRコード (400x400)
  - CSS `background-image: url(img/HERO_BG.webp)` でも `<img src="img/...">` でも可。置換の都合上、この5パス以外の画像参照は禁止。
- **パララックス必須**: スクロール連動の多層視差（transform: translate3d をrAFで更新する方式推奨。background-attachment: fixed はiOSで効かないので主役にしない）。加えて IntersectionObserver によるリビール、スクロール進捗連動の演出など「プロのWEBデザイナーを凌駕する」レベルの演出を。ただし effects の乱れ打ちではなく、統一されたコンセプトで。
- `prefers-reduced-motion: reduce` で視差・アニメーション停止。
- レスポンシブ必須（375px〜1920px）。横スクロール禁止。モバイルでは視差を軽量化してよい。
- JSはvanillaのみ。エラーなく動くこと。閉じタグ・属性クォート厳密に。
- ダーク/ライトのテーマ切替対応は不要。**各案が選んだ世界観に固定**してよい（その場合も見やすいコントラストを保つ）。
