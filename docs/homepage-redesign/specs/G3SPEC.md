# G3実装指示書「一台のカメラと一本の電流」— 審議会合意パッケージ

ベース: /tmp/claude-0/-home-user-juchou-group-MasterFile/19588573-b955-55e6-900a-2baa258d1b0b/scratchpad/variants/variant-g1.html をコピーして variant-g3.html を作り、以下を実装する。BRIEF.md/NEWFACE.md/SEISEN.mdの規律（整線美・写真禁止・縦書き禁止・SEO・パフォーマンス作法）は全て維持。

## 統一原則（最初に敷く）
- CSSカスタムプロパティ `--ease-tie: cubic-bezier(.2,1.4,.3,1)` を定義し、**全ての**トランジション/アニメーションのイージングをこれに統一（「急減速＋僅かなオーバーシュート＋カチッと静止」）。既存のease系を置換する。
- pinned（sticky）区間は2箇所まで・各120〜150vh。代わりに既存のセクション間の過大な余白を30〜40%圧縮し、ページ総スクロール量を大きく増やさない。
- 全演出はスクロール逆行に追従（scrub方式）。IntersectionObserverの一発発火は分岐など小要素のみに残してよい。
- reduced-motion: 全演出停止＋「全結線済み・ランプ全点灯・完成状態」の静止表示（既存方針の維持・拡張）。

## 1. 起「結束の一拍」ロード演出（1.5秒以内・1回のみ）
- ページロード直後: ヒーローの6色ケーブルが左ベンド側からラック上を右へ描画されていく（Canvasの描画区間をrAFタイムラインで0→100%、easeOutExpo、約900ms）。
- 続けて結束バンドが左から右へ順に「パチン」と締まる: 各バンドが scaleY 1.18→1.0 のスナップ＋1フレームの微発光（計約400ms、時差20ms刻み）。
- 同時に「充寵グループ」ロゴタイプがマスクリビール、サブコピー・CTAが時差で追従。
- 演出中もテキスト/CTAは即座に操作可能（演出は背景レイヤーに限定）。reduced-motionでは完成状態を即表示。

## 2. 承「スクロール＝通電」グローヘッド
- 縦幹線の描画先端に発光ヘッドを常駐: SVG幹線の現在の描画終端座標を getPointAtLength で取得し、radialGradientの光球＋短い残像トレイルを追従配置。
- スクロール速度（rAF内のscrollY差分をlerp減衰）→ 輝度と尾の長さに写像。停止時は呼吸するような微減衰。**上限を設け、チカチカした下品な明滅は禁止**（整線の静謐を守る）。
- ヘッドが近くを通過するセクション見出しは `--lit` カスタムプロパティ経由でふわっと照らされる（レイアウト不変）。
- 各セクションの分岐はscrub化し逆行に追従。
- feGaussianBlurは半径小さく固定 or box-shadow代替でモバイル負荷を抑える。

## 3. 転「同心円90°ベンド」ピン留めシーン（署名ショット）
- 現在素通りされているヒーロー直後の水平→垂直ベンドを、専用のシーンセクション（sticky・150vh）に昇格。
- スクロール進捗 t(0..1) に応じて: 6本のケーブルが外周から順に時差でRを描いて曲がる（dashoffsetのscrub・内外周の周速差を表現）。
- 同時にシーン全体のビジュアルレイヤーに transform: rotate(t × BEND_ROTATE) scale(1 + t×0.12) を適用（**カメラがケーブルと一緒に曲がる**）。テキスト・注記は回転レイヤーの外に置く。
- `const BEND_ROTATE = 8;` を**ファイル冒頭付近に1箇所だけ**定義（deg単位）。後工程でこの定数を90に書き換えた比較ビルドを作るので、8でも90でも破綻しないよう実装すること（90度時はscaleと原点を調整し、はみ出し・見切れが出ないように分岐してよい）。
- シーン中に図面注記「BEND R — CONCENTRIC 90°」がタイプライター的に浮かぶ。
- iOS Safariのsticky+transformチラつき対策（will-change / translateZ(0)）。

## 4. 結「端子台4拍フィナーレ」（120vh・スキップ付き）
- 最終CTAセクションの直前に端子台シーン（sticky・120vh）。端子台SVGを画面中央に大きく再構成（現在の小さな左端配置をやめる）。
- スクロール進捗を4区間に分割: ①6本の芯線＋フェルールが順に端子穴へ挿入（translateで差し込み） ②各端子のネジ頭が回転して締まる（SVG rotate 0→270deg、マイナス溝が回るのが見える） ③ランプが芯線色順に1灯ずつ点灯 ④「結線、完了。」が文字マスクで立ち上がり、CTAボタンの縁に通電パルスが一周。
- 全て可逆（逆スクロールで緩む・消灯する）。
- シーン中、画面隅に常時「スキップして相談する ↓」のミニリンクを表示（タップでCTAへ）。
- reduced-motionでは全結線・全点灯・完了文言表示の静止状態。
