## 決定事項とその理由

### 採用した方針

1. **写真ゼロ・全生成ビジュアル**: 現場は撮影禁止が多く、Manus CDN署名URLが2027年に失効する。Canvas 2D / SVG で生成し素材依存をなくす
2. **日本の実工法に忠実**: オーナーは現役電気工事士。架空のカッコいい電気工事ではなく、第二種電気工事士試験やネグロス/未来工業カタログの実際に基づく描写が必須
3. **rAF + transform のパララックスのみ**: `background-attachment: fixed` はiOSで壊れる。sticky/pinned も「バグに見える」で廃止
4. **writing-mode:vertical-rl 禁止**: Linux/Android系フォントの縦組みメトリクス欠如で文字が重なる。1文字ずつ `<i>` で縦積みなら可
5. **システムフォントスタック**: Google Fonts CDN への外部リクエストを避ける（自己完結HTML要件）

### 却下・廃止されたもの

1. **E案「通電前夜」の物語**: 「夜明け前に電気が通ってるとか何このセリフ？」→ 時間帯の比喩に頼る物語は廃止
2. **F案の6色ケーブルリボン**: 「ただのぐちゃぐちゃのケーブル」→ 整線（平行・結束・交差ゼロ）を主役に
3. **G1〜G3の6色並列ケーブル**: 日本の幹線は黒CVT/CVシースが数条。カラフルな6色が並ぶのは誤り
4. **フェルール（棒端子）＋ネジ端子台**: 盤内配線の世界。屋内配線シーンでは不使用。正しくはリングスリーブ圧着 or 差込形コネクタ
5. **Sticky/Pinned ヒーロー（300vh）**: オーナー実機テストで「同じとこでずっとスクロールさせられるのしんどい。一瞬バグだと思った」→ 1画面ヒーローに変更
6. **本番への無断デプロイ**: G3を無断で本番に出して怒られた。**「これを出して」と明言されるまで絶対に本番反映しない**

## 試したがダメだったこと

| 試みた内容 | 結果 | 理由 |
|---|---|---|
| `background-attachment: fixed` パララックス | iOS Safari で完全に壊れる | Webkit の仕様制限 |
| `writing-mode: vertical-rl` | Linux/Android で文字が重なる | CJK縦組みメトリクスの欠如 |
| Google Fonts (Noto Sans JP 等) | 外部リクエスト禁止に抵触 | 自己完結HTML要件 |
| 300vh sticky pinned ヒーロー | 「バグに見える」（オーナー実機テスト） | ユーザー体験として破綻 |
| WebGL で3D表現 | 未実施（Phase 2候補） | 現行Canvas 2Dで十分。将来拡張余地あり |

## 環境の落とし穴

- **Playwright**: Chromium は `/opt/pw-browsers/chromium` にプリインストール。`playwright install` は不要。`executablePath` を指定して使う
- **エージェントプロキシ**: Playwright で外部サイトにアクセスするとプロキシ経由で問題が出る。ローカルHTMLは `file://` プロトコルで開く
- **pnpm**: パッケージマネージャは pnpm。`npm` や `yarn` ではない
- **Node.js**: 22.x 系
- **テスト**: `pnpm test`（vitest）。65ファイル・551テスト。ホームページ再構築はテスト対象外（docs配下のモックアップ）

## 日本の電気工法 — 事実の絶対ルール

詳細は `docs/homepage-redesign/specs/JP-DENKI-FACTS.md` を参照。以下は最重要ルール:

- **幹線ケーブル(CV/CVT)**: シースは**黒**。端末付近に**赤・白・青の相別テープ**（RST=赤白青、オーナー標準）
- **ケーブルラック**: **はしご形（ラダー）、溶融亜鉛めっきの銀灰色**。親桁＋等ピッチの子桁(ラング)
- **屋内配線**: **灰色シースのVVFケーブル**、心線は黒・白・赤（緑=接地）
- **接続**: **リングスリーブ圧着**（工具の柄=黄色）or **差込形コネクタ**（透明ボディ）。フェルール不使用
- **金属管**: **ねじなし電線管E管**（鋼の銀色）。PF管（ベージュ/グレー）は露出可とう管用。CD管（オレンジ）は埋設専用
- **色数**: グラファイト地＋銀（めっき）＋黒（ケーブル）＋灰(VVF)＋赤白青（差し色）。彩度は低め

## オーナーの好み・却下されたもの（やり直し防止）

- **事実性 >> 見た目のカッコよさ**: 「リアルな写真」は不要だが「リアルな工法」は必須
- **整線美が主役**: 職人の誇りは綺麗な配線。揺れない、発光は控えめ
- **チープさNG**: G3の「フラットな色帯が横に並ぶ2.5D」は安っぽい。奥行き・質感が必要
- **ストーリーの破綻NG**: 意味不明な比喩より、事実に基づく静謐な表現
- **スクロールジャッキングNG**: 長時間のsticky/pinnedは「バグに見える」
- **無断デプロイ厳禁**: 過去に一度やって怒られた。絶対に許可なく本番反映しない
